## Research conventions

Each project separates scope, source provenance, implementation, validation, results, and limitations. Public or synthetic data are labeled explicitly. A planned capability is not treated as implemented until code and validation evidence exist.

## Repository layout

Typical project directories include src/, tests/, data/, artifacts/, reports/, references/, and decision records. Machine-local assistant instructions, caches, secrets, and runtime state are excluded from version control.

See docs/REPOSITORY_GUIDE.md for the common project structure.
